## Introduction and Overview

This tutorial focuses on building a local **MCP server** that works as an **Expense Tracker**.

## The MCP Ecosystem: MCP SDK vs. FastMCP

When building MCP servers in Python, two names often come up: **MCP SDK** and **FastMCP**.

### MCP SDK (`mcp` / `mcp-sdk`)

Anthropic’s official library, released in late 2023. It is powerful, but early versions were verbose and required significant boilerplate.

### FastMCP (v1)

FastMCP was created by **Jeremiah Lowin** as a simpler abstraction layer on top of the MCP SDK. It made building MCP servers significantly easier by allowing developers to expose Python functions as tools with decorators.

Its simplicity made it very popular, and many of its ideas influenced the official SDK ecosystem.

### FastMCP (v2)

By 2025, FastMCP evolved into an independent and feature-rich library.

Install it with:

```bash
pip install fastmcp
```

### Analogy

You can think of the relationship like this:

- **MCP SDK : FastMCP** = **WSGI : Flask**
- **MCP SDK : FastMCP** = **TensorFlow : Keras**

FastMCP is the more developer-friendly choice and is the library used throughout this tutorial.

## Building a Basic Demo Server

Before creating the expense tracker, let’s start with a simple MCP server that exposes two tools:

- rolling dice
- adding numbers

```python
from fastmcp import FastMCP

# Initialize the MCP Server
mcp = FastMCP("Demo Server")

@mcp.tool()
def roll_dice(num_dice: int) -> list[int]:
    """Rolls a specified number of dice."""
    import random
    return [random.randint(1, 6) for _ in range(num_dice)]

@mcp.tool()
def add_numbers(a: int, b: int) -> int:
    """Adds two numbers together."""
    return a + b
```

## Building the Expense Tracker Server

The core of this tutorial is an **Expense Tracker MCP server** backed by a local **SQLite** database named `expenses.db`.

---

## Feature 1: Database Initialization

The first step is to create the database and define the table schema.

```python
import sqlite3
from fastmcp import FastMCP

mcp = FastMCP("Expense Tracker")
DB_PATH = "expenses.db"

def init_db():
    """Initializes the SQLite database and creates the expenses table."""
    with sqlite3.connect(DB_PATH) as conn:
        cursor = conn.cursor()
        cursor.execute('''
            CREATE TABLE IF NOT EXISTS expenses (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                date TEXT,
                amount REAL,
                category TEXT,
                sub_category TEXT,
                note TEXT
            )
        ''')
        conn.commit()

init_db()
```

This creates an `expenses` table with the following fields:

- `id`
- `date`
- `amount`
- `category`
- `sub_category`
- `note`

## Feature 2: Adding and Listing Expenses

Next, expose tools to insert expense records and retrieve them over a date range.

```python
@mcp.tool()
def add_expense(date: str, amount: float, category: str, sub_category: str, note: str) -> str:
    """Add a new expense entry to the database."""
    with sqlite3.connect(DB_PATH) as conn:
        cursor = conn.cursor()
        cursor.execute(
            "INSERT INTO expenses (date, amount, category, sub_category, note) VALUES (?, ?, ?, ?, ?)",
            (date, amount, category, sub_category, note)
        )
        conn.commit()
    return "Expense added successfully."

@mcp.tool()
def list_expenses(start_date: str, end_date: str) -> list:
    """List all expense entries from the database within a given date range."""
    with sqlite3.connect(DB_PATH) as conn:
        cursor = conn.cursor()
        cursor.execute(
            "SELECT * FROM expenses WHERE date BETWEEN ? AND ? ORDER BY date ASC",
            (start_date, end_date)
        )
        return cursor.fetchall()
```

With these tools, the LLM can:

- add a new expense
- retrieve expenses between two dates
- display them in a user-friendly format

## Feature 3: Summarizing Expenses

This tool calculates the total amount spent in a date range, optionally filtered by category.

```python
@mcp.tool()
def summarize_expenses(start_date: str, end_date: str, category: str = None) -> float:
    """Summarize expenses by category within an inclusive date range."""
    with sqlite3.connect(DB_PATH) as conn:
        cursor = conn.cursor()

        query = "SELECT SUM(amount) FROM expenses WHERE date BETWEEN ? AND ?"
        params = [start_date, end_date]

        if category:
            query += " AND category = ?"
            params.append(category)

        cursor.execute(query, tuple(params))
        result = cursor.fetchone()[0]
        return result if result else 0.0
```

Examples of what this enables:

- “What did I spend in the last 7 days?”
- “How much did I spend on travel this month?”
- “Summarize my education expenses between August 1 and August 31.”

## Feature 4: Adding Resources for Category Consistency

One challenge with LLMs is inconsistent categorization.

For example, a cab ride might be categorized as:

- `Transport`
- `Transportation`
- `Travel`

This inconsistency makes aggregation and reporting unreliable.

### Solution

Create a `categories.json` file that defines approved categories and sub-categories, then expose it as an MCP resource.

```python
import json

@mcp.resource("file://categories.json")
def get_categories() -> str:
    """Provides the valid list of categories and sub-categories."""
    with open("categories.json", "r") as file:
        return file.read()
```

This allows Claude Desktop to read and use the resource when categorizing expenses.

### Why this matters

By attaching the resource in the prompt, you can instruct the LLM to only use categories from the provided JSON file, improving consistency and making reporting much more accurate.

## Bonus: FastMCP and FastAPI Synergy

FastMCP is heavily inspired by **FastAPI**.

If your business already has an expense backend implemented with FastAPI for web or mobile applications, you do not need to rewrite all your business logic to support MCP.

Instead, you can expose the existing API as MCP tools.

```python
from fastmcp import FastMCP
from main import app  # Existing FastAPI app

mcp_server = FastMCP.from_fastapi(app, name="Expense Tracker MCP")
```

Run it with:

```bash
uv run fastmcp dev server.py
```

This automatically exposes your FastAPI endpoints, such as:

- `/add_expense`
- `/get_expenses`

as MCP tools that Claude can invoke.
