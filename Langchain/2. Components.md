## 1. Introduction and Framework Philosophy

LangChain acts as an orchestrator—it simplifies the complex interactions between different AI components. It provides standard building blocks for prompts, model calls, tools, retrieval, and memory. It is **model-agnostic**, meaning you can switch from OpenAI's GPT models to Google's Gemini or Anthropic's Claude models with just 1–2 lines of code changes.

*   Conversational Chatbots
*   AI Knowledge Assistants (e.g., "Chat with PDF" apps using RAG)
*   Autonomous AI Agents

## 2. Component 1: Models

Models are the core interface through which your application communicates with external AI. Every company (OpenAI, Google, Anthropic) built their API differently. LangChain provides a standardized interface so you write code one way, and LangChain handles the specific API formatting behind the scenes.

**Two Types of Models in LangChain:**
1.  **Language Models (Chat Models):** "Text-In, Text-Out." You provide text, and it generates text. 
2.  **Embedding Models:** "Text-In, Vector-Out." You provide text, and it returns a numerical array (vector), essential for semantic search.

### Sample Code: Standardizing Model Calls
```python
from langchain_openai import ChatOpenAI
from langchain_anthropic import ChatAnthropic
from langchain_core.messages import HumanMessage, SystemMessage

messages = [
    SystemMessage(content="You are a helpful coding assistant."),
    HumanMessage(content="Explain LangChain in one sentence.")
]

# Using OpenAI
llm_openai = ChatOpenAI(model="gpt-4o")
print("OpenAI:", llm_openai.invoke(messages).content)

# Switching to Anthropic requires minimal code change
llm_claude = ChatAnthropic(model="claude-3-sonnet-20240229")
print("Claude:", llm_claude.invoke(messages).content)
```

## 3. Component 2: Prompts

Prompts are the inputs provided to an LLM. Because LLMs are highly sensitive to prompts, LangChain provides flexible tools to handle complex prompting techniques.

*   **Dynamic Prompts:** Creating reusable templates with placeholders.
*   **Role-Based Prompts:** Separating instructions into a System Prompt and a User Prompt.
*   **Few-Shot Prompting:** Giving the LLM examples of desired outputs before giving it the actual task to improve accuracy.

### Sample Code: Dynamic Prompt Templates
```python
from langchain_core.prompts import ChatPromptTemplate

# Creating a reusable, role-based dynamic template
prompt_template = ChatPromptTemplate.from_messages([
    ("system", "You are an expert in {subject}."),
    ("user", "Explain {topic} in a {tone} tone.")
])

# Filling the placeholders dynamically
final_prompt = prompt_template.invoke({
    "subject": "Physics",
    "topic": "Quantum Mechanics",
    "tone": "fun"
})

print(final_prompt)
```

## 4. Component 3: Chains

Chains are how you build pipelines in LangChain. In multi-step LLM applications, the output of one step often needs to become the input of the next. LangChain uses **LCEL (LangChain Expression Language)** with the pipe operator (`|`) to connect components seamlessly.

### Sample Code: LCEL Chain Execution
```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# 1. Define Model
llm = ChatOpenAI(model="gpt-4o")

# 2. Define Prompt
prompt = ChatPromptTemplate.from_template("Summarize this topic in one sentence: {topic}")

# 3. Define Output Parser (extracts raw text from the AI message object)
parser = StrOutputParser()

# 4. Build the Chain using LCEL (Prompt -> LLM -> Parser)
chain = prompt | llm | parser

# 5. Execute Pipeline
result = chain.invoke({"topic": "The Industrial Revolution"})
print(result)
```

## 5. Component 4: Indexes (RAG)

Indexes connect your LLM to external private knowledge sources (PDFs, internal databases) that the model wasn't natively trained on. This architecture is called **Retrieval-Augmented Generation (RAG)**.

**The 4 Sub-Components:**
1.  **Document Loaders:** Fetches raw data from its source.
2.  **Text Splitters:** Breaks massive documents into smaller chunks.
3.  **Vector Stores:** Stores the chunks as vector embeddings.
4.  **Retrievers:** Searches the Vector Store and retrieves relevant chunks for the LLM.

### Sample Code: RAG Implementation
```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_core.runnables import RunnablePassthrough

# 1. Load and Split Document
loader = TextLoader("company_policy.txt")
docs = loader.load()
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(docs)

# 2. Create Embeddings and Vector Store
embeddings = OpenAIEmbeddings()
vector_store = FAISS.from_documents(chunks, embeddings)

# 3. Create Retriever
retriever = vector_store.as_retriever(search_kwargs={"k": 2}) # Get top 2 results

# 4. Create RAG Chain
prompt = ChatPromptTemplate.from_template("""
Answer the question based only on the provided context:
Context: {context}
Question: {question}
""")

rag_chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt
    | ChatOpenAI(model="gpt-4o")
    | StrOutputParser()
)

print(rag_chain.invoke("What is the company notice period?"))
```

## 6. Component 5: Memory

By default, LLM APIs are stateless—they have no memory of past interactions. Memory components solve this by keeping track of the conversation history and automatically injecting it into the context of new prompts. 

*   **Conversation Buffer Memory:** Remembers the entire raw transcript.
*   **Buffer Window Memory:** Remembers only the last *N* messages to save API token costs.
*   **Summary Memory:** Uses an LLM to actively write a condensed summary of the conversation.

### Sample Code: Memory with LCEL
```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_core.chat_history import InMemoryChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory

# 1. Setup Prompt with a placeholder for history
prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant."),
    MessagesPlaceholder(variable_name="history"),
    ("human", "{question}")
])

chain = prompt | ChatOpenAI(model="gpt-4o")

# 2. Setup Message History
store = {}

def get_session_history(session_id: str):
    if session_id not in store:
        store[session_id] = InMemoryChatMessageHistory()
    return store[session_id]

# 3. Wrap Chain with Memory
chain_with_history = RunnableWithMessageHistory(
    chain,
    get_session_history,
    input_messages_key="question",
    history_messages_key="history",
)

# Call 1
chain_with_history.invoke(
    {"question": "Hi, my name is Alex!"},
    config={"configurable": {"session_id": "session_1"}}
)

# Call 2 (The model remembers the name)
response = chain_with_history.invoke(
    {"question": "What is my name?"},
    config={"configurable": {"session_id": "session_1"}}
)

print(response.content) # Output: "Your name is Alex!"
```

## 7. Component 6: Agents

While standard Chains follow a strict, hard-coded path, **Agents use the LLM as a reasoning engine to decide what to do next**. You give the Agent a goal and a set of **Tools** (like a Calculator or Web Search). The Agent analyzes the user's prompt, decides which tool to use, executes it, and iterates until the goal is met.

### Sample Code: Tool-Calling Agent
```python
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool
from langgraph.prebuilt import create_react_agent

# 1. Define custom tools using the @tool decorator
@tool
def get_weather(location: str) -> str:
    """Returns the weather for a specific location."""
    # In reality, this would hit a real Weather API
    if location.lower() == "london":
        return "It is 15°C and rainy."
    return "It is 22°C and sunny."

@tool
def calculate(expression: str) -> str:
    """Safely evaluates a math expression."""
    return str(eval(expression))

tools = [get_weather, calculate]

# 2. Initialize LLM (Must support tool calling)
llm = ChatOpenAI(model="gpt-4o")

# 3. Create the Agent 
agent_executor = create_react_agent(llm, tools)

# 4. Invoke the Agent
response = agent_executor.invoke({
    "messages": [HumanMessage(content="What is the weather in London? Also, what is 45 * 12?")]
})

# The agent autonomously decides to call the weather tool AND the calculator tool
print(response["messages"][-1].content)
```
